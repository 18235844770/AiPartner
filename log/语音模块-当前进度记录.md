### 已落地修复

1. **Worker**：`normalize_cosyvoice_instruct` 强制补全  
   `You are a helpful assistant. …<|endofprompt|>`  
   （禁止再把 endofprompt 剥掉）
2. **合成路径对齐 A_raw**：整段一次、`text_frontend=True`；增益后再峰值限幅（避免 1.7 硬削峰碎音）
3. **TTS 缓存失效**：`TTS_CONTRACT_VERSION = 5`
4. **默认音量**：1.7 → 1.25
5. **桌面播放**：`HTMLAudioElement` → **Web Audio**（`fetch` → `decodeAudioData` → 一次播放）
6. **桌面工作区**：可经 `.env.local` 绑定 ENFP「艺」  
   （`VITE_WORKSPACE_USER_ID` / `VITE_WORKSPACE_COMPANION_ID`）

## 待验收 / 未决

1. **桌面端 Web Audio 修复后的长句听感**（尤其「再来一次」类 100+ 字、可能 `yield_count=2` 的回复）  
   - 若本地 wav 顺、窗口仍卡 → 继续查播放调度  
   - 若窗口已顺 → 播放侧关闭；再评估官方分句接点是否要做更稳的拼接
2. **真流式 TTS**：当前产品主路径仍是整段合成后一次播放；`/tts/stream` 是合成后再切块，桌面主播报未走分块接力
3. **参考音色**：现多用官方 `zero_shot_prompt.wav`；定制音色/克隆未做产品化
4. **SenseVoice 权重许可**仍需正式核对（见真实模型验证记录）
5. Electron 内置拉起 8000 与外部 uvicorn 并存时，端口占用告警可忽略（以外部 API 为准）
