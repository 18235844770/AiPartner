# 语音模块真实模型验证记录

**日期：** 2026-11-07 / 08  
**平台决议：** Windows 原生 + CUDA（非 WSL2）  
**硬件：** NVIDIA GeForce RTX 3060 Ti 8GB / Driver 560.94 / CUDA 12.6（torch cu121）

## 结论

| 项 | 结果 |
|---|---|
| CUDA torch 2.5.1+cu121 | 通过 |
| SenseVoice（FunASR `iic/SenseVoiceSmall`，CPU） | 加载通过；静音样本识别为空文本（符合预期） |
| CosyVoice3 `Fun-CosyVoice3-0.5B-2512`（GPU fp16） | 加载 + 合成通过 |
| 单实例显存 | 加载增量 ≈ 3494 MB；合成峰值 ≈ **4293 MB**（8GB 卡可接受） |
| 单条中文短句延迟 | ≈ **3.6 s**（含推理；音频约 2.7–3.3 s，RTF ≈ 1.07） |
| Worker `/health` | `sensevoice` + `cosyvoice3`，`status=ok`，GPU 可见 |
| `POST /v1/tts`（UTF-8） | 通过（`duration_ms≈3320`）；PowerShell 默认编码会把中文变成 `??` 导致极短音频 |

## 环境与依赖要点

1. **C 盘空间**：uv 默认缓存曾写满 C:；已改用 `D:\AiLove\.cache\uv` 与 `TMP/TEMP`。
2. **NumPy**：必须 `<2`（`numpy==1.26.4`），否则 onnxruntime 报 `_ARRAY_API`。
3. **setuptools**：需 `setuptools==69.5.1`（过新版本无 `pkg_resources`，lightning 失败）。
4. **权重下载**：Hugging Face / hf-mirror SSL 不稳定；**ModelScope** 成功。
5. CosyVoice 仓库：`apps/audio_worker/vendor/CosyVoice`（含 Matcha-TTS submodule）。
6. 输出 WAV：强制 PCM16，避免 float WAV 导致 Python `wave` 无法读。

## 开关

```env
ASR_BACKEND=sensevoice
TTS_BACKEND=cosyvoice3
ASR_MODEL_NAME=iic/SenseVoiceSmall
TTS_MODEL_NAME=Fun-CosyVoice3-0.5B-2512
COSYVOICE_REPO=./vendor/CosyVoice
TTS_FP16=true
```

安装脚本：`apps/audio_worker/scripts/setup_real_models.ps1`

## 剩余风险

- CosyVoice Windows 依赖面仍脆（whisper / pyarrow / setuptools 版本敏感）。
- 长文本、多并发未压测；设计仍为单队列。
- 默认参考音频为官方 `zero_shot_prompt.wav`；正式音色需业务侧配置 reference。
