# Midnight · 夜猫 静态素材 V1

设计基准 440 × 956，背景图导出为 1320 × 2868（3x）。

## 目录

- backgrounds：四页纯背景，无角色、文字、控件（依据定稿重新生成背景，场景和光影存在细微差异）。
- characters：八态全身角色，480 × 480 RGBA，底部对齐，保留原画比例。
- avatars：八态头像及原聊天页头像，210 × 210 RGBA。
- decorations：独立星芒、月牙。
- icons：导航、设置、聊天操作图标，120 × 120 PNG，由定稿位图切出。
- reference：四页定稿参考图，1320 × 2868。

## 状态映射

| 文件名 | 状态 |
|---|---|
| idle | 默认 |
| happy | 开心 |
| shy | 害羞 |
| curious | 好奇 |
| angry | 生气 |
| sad | 失落 |
| sleeping | 睡眠 |
| affectionate | 亲昵 |

角色静态图与动画图均为 480 × 480 画布。切换时以底部中心为定位锚点。角色和头像透明背景，可叠加在独立场景上。

页面文字、输入框、卡片、聊天气泡和按钮背景建议使用原生组件/CSS实现，避免将文字烘焙入素材。原设计图是位图概念稿，所有放大导出并非原生矢量精度。

背景重建使用原定稿作为参考，去除全部角色、文字、图标、控件及星芒，保留黑红光影、窗帘、月光、烛光和绒面场景。
