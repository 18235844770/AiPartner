配置目标是：普通话自然、偏日常交流、能够表现开心、温柔、委屈、嫉妒和生气，不要播音腔。
1. Fish Audio
推荐优先测试
推荐模型： s2.1-pro








fish.audio


基础配置：
参数	建议值
Model	s2.1-pro
Language	Chinese
Format	WAV（接口支持时）
语速	默认，先不额外调整
情绪控制	文本内自然语言标签
输出模式	第一轮非流式，第二轮流式

Fish Audio S2 系列通过文本中的方括号指令控制表达，不需要单独的 emotion 参数。
GitHub+1


情绪配置：
情绪	文本指令
Neutral	[natural conversational tone]
Joy	[happy, cheerful, slightly excited]
Affection	[warm, gentle, intimate]
Sadness	[sad, slightly disappointed]
Jealousy	[slightly jealous, mildly annoyed]
Anger	[angry, firm, restrained]
Tired	[tired, relaxed, slower pace]

测试示例：
[warm, gentle, intimate]
没关系，你不用急着回答，我可以慢慢听你说。

[slightly jealous, mildly annoyed]
哦，原来你今天和她聊了这么久啊。

[angry, firm, restrained]
我不是不讲道理，只是你真的有点过分了。


建议：先不要叠加多个复杂标签，观察模型对单个自然语言指令的响应，再逐步增加细节。

官方文档：Fish Audio API
2. 火山引擎
重点测试中文情绪表现
推荐模型： 豆包语音合成大模型 2.0

推荐预置音色： 灿灿 2.0（BV700_V2_streaming）








volcengine.com


选择它的原因是灿灿 2.0 支持较丰富的情绪和风格，包括开心、悲伤、愤怒、嗔怪、傲娇、安慰鼓励、撒娇等，比较适合 AI 伴侣的表达需求。
火山引擎文档


基础配置：
参数	建议值
Model	豆包语音合成大模型 2.0
Voice Type	BV700_V2_streaming
Language	中文普通话
Sample Rate	24000 Hz（接口支持时）
Format	WAV 或 PCM
Speed	1.0，默认
Volume	默认
Pitch	默认
TagParse	true
QuoteUserQuestion	true

情绪控制使用火山引擎的自然语言指令标签：
{{"additions":{"context_texts":["语气自然、放松，像日常聊天"]} }}
今天下班有点早，突然不知道该做什么了。

{{"additions":{"context_texts":["语气开心、轻快，带一点笑意"]} }}
哈哈哈，我刚刚发现一件特别有意思的事情！

{{"additions":{"context_texts":["语气温柔、亲近，语速稍慢"]} }}
没关系，你不用急着回答，我可以慢慢听你说。

{{"additions":{"context_texts":["带有轻微吃醋和嗔怪，语气中有一点不满"]} }}
哦，原来你今天和她聊了这么久啊。

{{"additions":{"context_texts":["明显生气，但克制情绪，不要大声喊叫"]} }}
我不是不讲道理，只是你真的有点过分了。


这里有一个重要配置：开启 TagParse，否则标签可能不会被识别为语音表达指令。标签格式、作用范围和上下文设置以火山引擎文档为准。
火山引擎文档+1


特别建议： 火山引擎的优势可能在情绪风格，而不只是基础音色。除了常规六种情绪，还应该额外测试「嗔怪」「傲娇」「撒娇」三个风格，看看是否更符合你希望的陪伴者人格。

官方文档：火山引擎语音合成 · 语音表达控制文档
3. MiniMax
推荐作为质量对照组
推荐模型： speech-2.8-hd








fal.ai


基础配置：
参数	建议值
Model	speech-2.8-hd
Voice ID	选择中文预置女声音色
Speed	0.95
Volume	1.0
Pitch	0
Emotion	auto（基础测试）
Sample Rate	32000
Format	wav
Channel	1
Stream	false（第一轮）

情绪参数：
情绪	API 参数
Neutral	auto
Joy	happy
Affection	calm
Sadness	sad
Jealousy	auto
Anger	angry
Tired	calm

MiniMax 的情绪参数是预设枚举，并不是可以任意填写的自然语言描述。嫉妒这种复合情绪，建议先用 auto，通过文本上下文观察模型表现。
GitHub


推荐测试请求配置：
{
  "model": "speech-2.8-hd",
  "text": "没关系，你不用急着回答，我可以慢慢听你说。",
  "stream": false,
  "voice_setting": {
    "voice_id": "选择的中文预置音色",
    "speed": 0.95,
    "vol": 1.0,
    "pitch": 0,
    "emotion": "calm"
  },
  "audio_setting": {
    "sample_rate": 32000,
    "format": "wav",
    "channel": 1
  }
}


注意：这里的 voice_id 需要从你账号实际可用的预置音色列表中选择，不能直接把示例文字作为真实 ID。

官方入口：MiniMax 开放平台 · 语音 API 文档

- 火山引擎：重点听中文表达，以及嗔怪、撒娇、傲娇等情绪风格。
